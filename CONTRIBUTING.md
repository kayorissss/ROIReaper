# 🤝 Как помочь ROIReaper

Спасибо за интерес к «Жнецу Роя»! Ниже — простые правила, чтобы ваш отчёт об ошибке или пул-реквест быстро пригодился.

## 🐞 Сообщение об ошибке

1. Убедитесь, что стоит последняя версия (**Настройки → Обновления**).
2. Поищите похожую проблему среди [issues](https://github.com/kayorissss/ROIReaper/issues).
3. Создайте issue через [готовый шаблон](https://github.com/kayorissss/ROIReaper/issues/new/choose) и укажите:
   - режим, в котором всё сломалось;
   - версию приложения (плашка на главном экране) и вариант сборки — Portable или установщик;
   - версию Windows;
   - шаги воспроизведения и что произошло вместо ожидаемого.

Особенно ценны **зависания партий** (дурак, шашки, блэкджек): опишите последний ход и положение на столе.

## 💡 Идея новой игры или фичи

Создайте issue с шаблоном «Идея» и расскажите:
- какую проблему это решает;
- механику, экраны и кнопки;
- управление (мы поддерживаем WASD, стрелки и мышь).

## 🔧 Пул-реквесты

```bash
git clone https://github.com/kayorissss/ROIReaper.git
npm install
npm start          # http://localhost:8848/index.html
npm test           # все тесты должны быть зелёными
```

Перед отправкой PR:

- [ ] `npm test` проходит без ошибок;
- [ ] для изменений в играх желательно прогнать `node tools/stress-games.js`;
- [ ] интерфейс проверен и в тёмной, и в светлой теме;
- [ ] подписи и тексты — на русском, стиль — сдержанный, «офисный»;
- [ ] шрифт только Unbounded (он уже встроен в приложение);
- [ ] новые настройки сохраняются через `Store` и переживают перезапуск;
- [ ] не добавлены внешние сетевые зависимости — приложение работает офлайн.

### Стиль кода

- Отступы — 2 пробела, кодировка UTF-8, перевод строк LF (см. [.editorconfig](.editorconfig)).
- Новые игры кладите в `src/renderer/js/games/` и регистрируйте в общем меню.
- Для Windows-скриптов (`*.cmd`, `*.vbs`, `*.ps1`) переводы строк CRLF — сборка делает это сама.

### Сборка дистрибутивов

`npm run dist` собирает в `dist/` оба файла — Portable ZIP и установочный EXE.
Релизная сборка на CI повторяет это автоматически при пуше тега `v*`
(см. [.github/workflows/release.yml](.github/workflows/release.yml)).

## 📐 Ориентиры дизайна

- Тёмная тема — основная: чёрный и тёмно-серый фон, белый/серый текст, янтарный акцент.
- Светлая тема должна оставаться контрастной и читаемой.
- Анимации плавные, без «кислотных» цветов; у пользователя есть настройка их отключения.
- Всё должно работать с клавиатуры и мыши, без обязательного интернета.
