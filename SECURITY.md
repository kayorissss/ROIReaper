# 🔒 Политика безопасности

## Поддерживаемые версии

Обновления безопасности и исправления выпускаются только для последней версии.
Приложение само проверяет обновления в **Настройки → Обновления**; используйте актуальный релиз.

| Версия | Поддерживается |
|---|---|
| последняя (1.0.x) | ✅ да |
| более старые | ❌ обновитесь до последней |

## Как сообщить об уязвимости

Пожалуйста, **не публикуйте** детали уязвимости в открытых issues.

1. Откройте [приватное уведомление безопасности](https://github.com/kayorissss/ROIReaper/security/advisories/new)
   (GitHub → вкладка **Security → Report a vulnerability**), либо создайте issue с заголовком
   `[SECURITY]` без технических деталей — мы свяжемся с вами.
2. Опишите: версию приложения, вариант сборки (Portable/установщик), версию Windows,
   сценарий воспроизведения и ожидаемые последствия.
3. Пожалуйста, дайте разумное время на исправление до публикации деталей.

## Модель безопасности

- Приложение — статичные HTML/CSS/JS под локальным лаунчером; оно **не запускает удалённый код**,
  не имеет телеметрии и не передаёт персональные данные.
- Единственные исходящие запросы — проверка релизов и скачивание обновления
  по явному действию пользователя, только с `github.com/kayorissss/ROIReaper`.
- Раздел «О компьютере» выполняет локальные read-only WMI-запросы и ничего не отправляет в сеть.
- Сохранение лежит в локальном профиле (`profile/`) и может быть экспортировано/импортировано пользователем.
- Установщик не запрашивает UAC и ставится только в профиль текущего пользователя (`%LOCALAPPDATA%`).

## Целостность релизов

- Контрольные суммы SHA-256 публикуются в заметках каждого релиза и в логе релизной сборки.
- ZIP и EXE собираются автоматически в GitHub Actions из исходников соответствующего тега.
